One original one-line joke about office life, written for the
[make.fun bounty "Make the AI Judge Laugh: Office Jokes"](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a).
`main.py` writes exactly that line to `entry.txt`.

> My out-of-office reply is the most honest document this company has ever produced.

## Run it

```sh
python3 main.py
```

This writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt` when `MAKEFUN_OUTPUT_DIR` is not set).
